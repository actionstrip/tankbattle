# 탱크배틀 효과음 목록

현재 게임에는 소리가 하나도 없다. 아래는 지금 구현된 기능 기준으로 필요한 효과음과, 각 소리를 재생할 코드 위치다.

- **우선순위**: 1 = 꼭 필요(없으면 타격감이 없음), 2 = 있으면 좋음, 3 = 나중에
- **길이**는 대략적인 목표치. 루프 표시가 있는 소리는 이음매 없이 반복되게 만든다.
- 파일 형식은 `.ogg` + `.mp3`(사파리 대비) 두 벌을 권장. 경로 예: `sounds/<ID>.ogg`

## 구현 메모

- 처음 넣을 때는 **우선순위 1**(11개)만 있어도 타격감이 크게 좋아진다.
- 루프 소리(`tank_move`, `barrel_aim`, `charge_loop`, `shell_whistle`)는 키를 떼거나 상태가 바뀔 때 반드시 정지한다. 짧게 페이드아웃하면 뚝 끊기지 않는다.
- 3연발처럼 같은 소리가 동시에 여러 번 나면 볼륨이 튀므로, 같은 ID는 동시에 최대 3개까지만 재생한다.
- 화면 밖에서 난 폭발(카메라에서 먼 착탄)은 볼륨을 낮추면 공간감이 생긴다.
- 브라우저는 사용자가 한 번 클릭하기 전까지 소리를 막으므로, 타이틀에서 모드 버튼을 누를 때 오디오를 시작하면 된다.
